📝 Misi 1 — Microsoft Word

Mengolah kata dan menyusun dokumen.

Apa itu Microsoft Word?

Microsoft Word adalah aplikasi pengolah kata untuk membuat, mengedit, memformat, menyimpan, dan mencetak dokumen seperti surat, laporan, makalah, serta undangan.

Fitur penting

  • Font: mengatur jenis, ukuran, dan warna huruf.
  • Paragraph: mengatur perataan, spasi, dan indentasi.
  • Insert: menambahkan tabel, gambar, bentuk, dan nomor halaman.
  • Layout: mengatur ukuran kertas, margin, dan orientasi.
  • Review: memeriksa ejaan dan memberi komentar.
Tips: gunakan judul dan subjudul secara konsisten agar dokumen mudah dibaca.

🎯 Tantangan praktik

  1. Buat dokumen berjudul “Kegiatan Literasi Sekolah”.
  2. Ketik dua paragraf tentang kegiatan membaca.
  3. Buat judul tebal dan rata tengah.
  4. Tambahkan satu gambar atau tabel sederhana.
  5. Simpan dengan nama Latihan_Word_Nama.

📊 Misi 2 — Microsoft Excel

Mengolah angka dan membaca data.

Apa itu Microsoft Excel?

Microsoft Excel adalah aplikasi spreadsheet untuk memasukkan data, melakukan perhitungan, menganalisis informasi, dan menyajikan data dalam tabel atau grafik.

Istilah dasar

  • Workbook: file Excel.
  • Worksheet: lembar kerja.
  • Cell: kotak pertemuan kolom dan baris, misalnya A1.
  • Range: kumpulan sel, misalnya A1:A5.
  • Formula: rumus yang diawali tanda sama dengan (=).

Rumus dasar

RumusFungsi
=SUM(A1:A5)Menjumlahkan data
=AVERAGE(A1:A5)Menghitung rata-rata
=MAX(A1:A5)Mencari nilai terbesar
=MIN(A1:A5)Mencari nilai terkecil
=COUNT(A1:A5)Menghitung sel berisi angka
=COUNTIF(A1:A5,"Lulus")Menghitung sesuai kriteria

🎯 Tantangan praktik

  1. Buat tabel nama siswa dan nilai tiga tugas.
  2. Hitung jumlah nilai menggunakan SUM.
  3. Hitung rata-rata menggunakan AVERAGE.
  4. Tentukan nilai tertinggi dan terendah.
  5. Buat grafik batang dari data nilai.

🎞️ Misi 3 — Microsoft PowerPoint

Mengubah gagasan menjadi presentasi visual.

Apa itu PowerPoint?

Microsoft PowerPoint adalah aplikasi untuk membuat dan menampilkan presentasi berbentuk slide. Presentasi dapat berisi teks, gambar, tabel, grafik, audio, dan video.

Fitur penting

  • New Slide: menambah slide.
  • Layout: memilih susunan isi slide.
  • Design/Theme: mengatur tampilan dan tema.
  • Transition: efek perpindahan antarslide.
  • Animation: efek pada objek di dalam slide.
  • Slide Show: menampilkan presentasi.
Tips desain: satu slide sebaiknya memuat satu gagasan utama. Gunakan teks singkat, ukuran huruf terbaca, dan warna yang kontras.

🎯 Tantangan praktik

  1. Buat presentasi 4 slide bertema “Bijak Menggunakan Teknologi”.
  2. Slide 1: judul dan identitas.
  3. Slide 2: pengertian teknologi digital.
  4. Slide 3: manfaat dan risiko.
  5. Slide 4: kesimpulan dan ajakan.
  6. Gunakan tema, gambar, dan transisi secukupnya.
